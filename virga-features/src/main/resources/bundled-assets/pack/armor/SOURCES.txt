Virga Inventory Armor Runtime Assets

Minecraft geometry semantics, equipment JSON, trim pattern definitions, trim material definitions,
trim color palettes, and `textures/misc/enchanted_glint_armor.png`:
- Source: local Minecraft Java Edition 26.1.2 client JAR
- Client JAR SHA-256: B1B3158572666445EFF01E82FAD8C7DE2E4953DB6D354F311730D77A8359D0B0
- Copyright: Mojang Studios / Microsoft; redistribution is subject to the Minecraft EULA.

The deterministic static armor glint frame follows the 26.1.2 client constants: armor texture,
0.16 UV scale, 10-degree rotation, default 0.75 glint strength, and GLINT `SRC_COLOR + ONE`
blending. Animation time is intentionally frozen for reproducible PNG output.
The glint pass uses white vertex modulation independently from the equipment dye color; leather
dye applies only to the dyeable base equipment layer.

32x equipment, trim-mask and item textures:
- Source: Faithful 32x / 26.3 (equipment textures identical to the previously bundled 26.2 set)
- Source ZIP SHA-256: 596035002E8C369CA673B5B922CD532A38A2AAABE80F317F5AC4D5C7680C7BF2
- Project: https://faithfulpack.net/
- Licensing information remains available in the bundled Faithful theme and project notices.

Faithful does not provide leather_chestplate_overlay.png in this pack; that one transparent
overlay is sourced from the same Minecraft 26.1.2 client and is scaled with nearest-neighbor
sampling over the 32x Faithful base texture.
